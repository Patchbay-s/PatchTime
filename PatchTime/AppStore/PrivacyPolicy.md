# Politique de confidentialité — PatchTime

Dernière mise à jour : 15 octobre 2026

PatchTime n'a pas de compte utilisateur ni de serveur applicatif. Les horaires, repas, congés, employeurs, contrats, profils de taux et préférences sont enregistrés dans la base de données de l'app, puis synchronisés via CloudKit dans la base privée de votre compte iCloud. L'équipe PatchTime n'a pas accès à cette base.

Les widgets lisent un résumé local de vos données. Les rappels et alertes sont programmés sur votre appareil. Pour télécharger les jours fériés français, l'app consulte `calendrier.api.gouv.fr` sans transmettre de donnée personnelle.

Vous pouvez consulter, modifier et exporter vos données depuis l'app. Supprimez les entrées dans PatchTime et gérez les copies iCloud depuis les réglages de votre compte Apple. Vous pouvez déposer une réclamation auprès de la CNIL (cnil.fr).

Pour toute question relative à cette politique ou à vos données, consultez [l'assistance PatchTime](https://patchbay-s.github.io/PatchTime/).
