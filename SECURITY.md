# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting form:

https://github.com/Patchbay-s/PatchTime/security/advisories/new

Include the affected version or commit, impact, and reproducible steps. Do not attach real employee records, credentials, or other personal data.

If private vulnerability reporting is unavailable, contact the repository maintainers privately through GitHub before sharing technical details.

## Supported versions

Security fixes are prepared for the latest version on the `main` branch. Older versions may not receive updates.
